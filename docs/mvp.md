# MVP

## Estado

La base ejecutable está implementada: registro de eventos, vault Markdown, API, MCP,
adaptador Graphify, propuestas con aprobación y visor local. La siguiente validación usa un flujo
real de marketing o ventas para comparar dos versiones bajo métricas equivalentes.

## Caso inicial

Mejorar un grafo de producción de contenido conectado con Postiz:

```text
objetivo
-> investigación
-> selección de tema
-> redacción
-> revisión
-> aprobación
-> programación
-> publicación
-> medición
-> aprendizaje
```

## Demostración de valor

1. Ejecutar la versión 1 al menos tres veces con evidencia real o un conjunto de evaluación controlado.
2. Registrar tiempos, correcciones, errores, aprobaciones y resultados disponibles.
3. Detectar un problema repetido.
4. Crear una propuesta de mejora con fuentes y explicación.
5. Producir la versión 2 sin reemplazar la versión 1.
6. Evaluar ambas versiones bajo criterios equivalentes.
7. Mostrar la diferencia en HORO Graph Studio.
8. Aprobar o rechazar la promoción y demostrar el rollback.

## Criterios de aceptación

- Cada ejecución identifica las versiones exactas del grafo y los skills.
- Cada cambio puede rastrearse hasta evidencia concreta.
- El visor distingue plan, ejecución real y propuesta.
- Ninguna mejora alcanza producción sin aprobación.
- La versión anterior permanece recuperable.
- Hermes puede consultar el conocimiento mediante una interfaz definida.
- El adaptador de Graphify puede retirarse sin perder el registro operacional.
- El sistema mantiene separación entre empresas.

## Fuera del primer MVP

- Marketplace de skills.
- Edición visual completa de cualquier grafo.
- Optimización autónoma sin aprobación.
- Facturación y administración empresarial completa.
- Compatibilidad exhaustiva con todos los runtimes.
