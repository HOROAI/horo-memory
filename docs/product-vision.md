# Visión del producto

Los modelos y los paquetes de skills se están convirtiendo en componentes intercambiables. El problema que permanece es que los agentes ejecutan tareas sin conservar una explicación estructurada de qué funcionó, qué falló, qué cambió y por qué la siguiente versión debería ser mejor.

HORO Loop convierte cada ejecución en evidencia reutilizable y cada mejora en un cambio trazable.

## Usuario inicial

Equipos que operan agentes de marketing y ventas sobre Hermes, Codex, Claude u otros runtimes y necesitan:

- comprender cómo trabajan;
- auditar decisiones y acciones;
- comparar versiones de un procedimiento;
- mantener conocimiento por empresa;
- mejorar sin permitir cambios silenciosos en producción.

## Promesa

Conecta el conocimiento, la ejecución y los resultados de tus agentes. Observa cómo trabajan, entiende por qué cambian y promueve únicamente las mejoras que puedas verificar.

## Diferenciación

HORO Loop no vende otro agente genérico ni otra biblioteca de prompts. Su valor es el ciclo cerrado:

```text
ejecución -> evidencia -> aprendizaje -> propuesta -> evaluación -> aprobación -> nueva versión
```

## Principios

- El grafo y los skills de producción nunca se modifican silenciosamente.
- Cada afirmación importante mantiene procedencia.
- El conocimiento derivado no sustituye la fuente de verdad.
- Las mejoras son versionadas, evaluables y reversibles.
- Cada empresa conserva aislamiento de datos y contexto.
- Los adaptadores evitan depender de un solo runtime o proveedor.
